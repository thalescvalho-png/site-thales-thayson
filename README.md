# Site — Thales Carvalho & Thayson Azevedo

## Como editar (sem mexer em código)

1. Acesse **https://app.pagescms.org** e entre com sua conta do GitHub.
2. Escolha este repositório.
3. Clique em **Conteúdo do site**, altere textos, músicas, trajetória ou fotos e clique em **Save**.
4. Em cerca de 1 minuto, o site atualiza sozinho.

## Onde fica cada coisa

- `content/site.json`: todos os textos, links e listas (é o que o painel edita)
- `img/`: as fotos
- `index.html`, `style.css` e `app.js`: estrutura, visual e funcionamento (só mexa se quiser mudar o layout)
- `.pages.yml`: configuração do painel de edição
